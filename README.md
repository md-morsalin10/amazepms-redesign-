## 📖 Project Context & Objectives

This project was developed as part of a **Web Developer / UI Developer hiring assignment** for **Dacitos Technologies Pvt. Ltd.** The primary objective was to deliver a complete redesign and modern UI implementation for the [Amaze PMS website](https://www.amazepms.com). 

The focus was on creating a highly aesthetic, premium user experience with smooth micro-interactions, responsive layouts, and robust modern web architecture.

---

## ✨ Key Highlights & Features

- **Hero Section**: A modern hero area with dynamic micro-interactions to capture user attention instantly.
- **Animated About Us**: A creatively designed section featuring a layered image stack and a floating dot grid animation for a sophisticated feel.
- **Interactive Gallery Grid**: An engaging media gallery with smooth scale-up transitions, glowing border hover effects, and an integrated `ImageModal` lightbox for immersive viewing.
- **Fully Responsive & Accessible**: Meticulously crafted to look perfect across all devices (Desktop, Tablet, Mobile) with seamless Light/Dark Theme compatibility.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js (App Router)](https://nextjs.org/)
- **Library**: [React](https://reactjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)

## 🚀 Local Setup & Installation

Follow these instructions to run the project locally.

1. **Clone the repository:**
   ```bash
   git clone <your-github-repo-url>
   cd amaze-pms-redesign
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **View the application:**
   Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
